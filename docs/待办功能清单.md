## P1 — 重要功能，提升可用性

### 1. RSS 订阅

Django 内置支持，无需第三方包：

```python
# blog/feeds.py
from django.contrib.syndication.views import Feed
from django.urls import reverse
from .models import Post

class LatestPostsFeed(Feed):
    title = 'MyBlog'
    link = '/'
    description = 'MyBlog 最新文章'

    def items(self):
        return Post.objects.filter(status='published')[:10]

    def item_title(self, item):
        return item.title

    def item_description(self, item):
        return item.desc

    def item_link(self, item):
        return reverse('blog:post_detail', args=[item.id])
```

只需加一个 URL 路由。

### 2. 文章缩略图 / 封面图

列表页和首页全是文字，缺少视觉元素。

**方案：** Post 模型加 `cover = models.ImageField(upload_to='covers/%Y/%m', blank=True, null=True)`，列表页展示缩略图，详情页展示封面大图。

### 3. 阅读时间估算

详情页显示「预计阅读 5 分钟」：

```python
@property
def reading_time(self):
    """估算阅读时间（分钟），中文按 300 字/分钟"""
    return max(1, round(len(self.content) / 300))
```

## P2 — 锦上添花

### 5. 站点地图 sitemap.xml

SEO 基础配置，Django 自带 `django.contrib.sitemaps`：

```python
# blog/sitemaps.py
from django.contrib.sitemaps import Sitemap
from .models import Post

class PostSitemap(Sitemap):
    changefreq = 'weekly'
    priority = 0.8

    def items(self):
        return Post.objects.filter(status='published')

    def lastmod(self, obj):
        return obj.pub_date
```

在根 URL 配置加入 `sitemap.xml` 路由即可。

### 6. 友情链接

独立模型 + 后台管理 + 前端展示：

```python
class Link(models.Model):
    name = models.CharField('名称', max_length=50)
    url = models.URLField('链接')
    sort = models.IntegerField('排序', default=1, help_text='越小越靠前')
    is_visible = models.BooleanField('是否显示', default=True)
```
